# Security Policy

## Supported versions

FlyThe BG is an actively maintained open-source project. Security fixes are prioritized for the current `main` branch and the latest published deployment.

## Reporting a vulnerability

Please do not disclose a suspected security vulnerability in a public issue.

Report security concerns privately to **stackpilotfe@outlook.com** with the subject line **Security Report — FlyThe BG**.

Please include, when possible:

- A clear description of the issue
- Steps to reproduce it
- The affected page, component, or workflow
- The potential impact
- A minimal proof of concept or screenshots, if safe to provide

Please avoid including passwords, API tokens, private images, personal documents, or other sensitive information in the report.

## Response

We will review reports in good faith and may ask for additional information needed to reproduce or assess the issue. Please allow reasonable time for investigation and remediation before making a vulnerability public.

## Privacy-sensitive workflows

Fly The BG is designed around browser-first processing for supported editing workflows. Security reports involving unexpected uploads, data leakage, exposed credentials, unsafe third-party integrations, or bypasses of privacy controls are especially important.
