# Contributing to FlyThe BG

Thank you for your interest in FlyThe BG.

FlyThe BG is an independent, non-commercial open-source project. Contributions are welcome from people who want to improve the software, documentation, accessibility, privacy, performance, and community experience.

## Before you contribute

1. Read the [Code of Conduct](CODE_OF_CONDUCT.md).
2. Check existing issues and pull requests before starting duplicate work.
3. For substantial changes, open an issue first so the proposed direction can be discussed.
4. Keep contributions focused, understandable, and consistent with the project's privacy-first and browser-first goals.

## What we welcome

- Bug fixes and reliability improvements
- Accessibility and responsive-design improvements
- Performance improvements
- Browser compatibility fixes
- Privacy and security improvements
- Documentation and examples
- Tests and developer tooling
- New open-source features that fit the project's scope

## Pull requests

Please include:

- A clear description of the change
- The reason the change is useful
- Testing performed locally
- Screenshots or recordings for meaningful UI changes when practical
- Any relevant issue or discussion reference

Before submitting, run the checks documented in the repository README, including the relevant test, typecheck, and build commands.
